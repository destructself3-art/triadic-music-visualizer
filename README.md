# Triadic — музыкальный визуализатор в духе Баухауза

> Shapes that hear the beat. Круги, квадраты и треугольники танцуют под музыку: бочка, малый барабан, бас и хай-хэты двигают разные фигуры. Отсылка к «Триадическому балету» Оскара Шлеммера (1922).

## О проекте

Визуализатор разбирает трек на отдельные ударные и частоты и превращает их в живой баухауз-плакат. Источник звука — встроенный демо-трек, свои файлы или микрофон. Всё написано без библиотек, на чистом Canvas 2D и Web Audio.

| **Circles** | «Несколько кругов» Кандинского, 1926 |

## Что внутри

- **Анализ ритма.** Onset-детекция по spectral flux отдельно для бочки (35–150 Гц), малого барабана (1,5–5 кГц) и хэтов (7–14 кГц). Оценка BPM, тап-темп (`T`) и детекция дропов. В HUD видны BPM, доли, номер такта и уровни L/M/H.
- **Синтезированный демо-трек.** «Formtanz» (122 BPM, ля минор, 32 такта) генерируется прямо в браузере осцилляторами Web Audio, аудиофайлов нет.
- **Любой звук.** Drag-and-drop и очередь файлов (MP3, WAV, OGG, FLAC, M4A…), таймлайн-волна с перемоткой, вход с микрофона, Media Session API.
- **Авто-хореография.** Сцены сами меняются на дропах и каждые 32 такта.
- **Оформление.** 4 палитры (Classic, Night, Riso, Mono), текстура бумаги и безопасный режим без вспышек.
- **Экспорт.** Постер в PNG и запись видео через MediaRecorder (webm или mp4).
- Zen-режим (`H`), полноэкранный режим, ссылка на образ через URL-хэш, сохранение настроек, EN/RU.

## Стек

Vanilla JS · Canvas 2D · Web Audio API (AnalyserNode, синтез на осцилляторах) · MediaRecorder · Google Fonts (Jost, IBM Plex Mono)

## Запуск

Один файл без сборки. Достаточно открыть `index.html` в браузере.

Если браузер не даёт доступ к микрофону со страницы, открытой из файла, запустите локальный сервер:

```bash
python -m http.server 8000
```
